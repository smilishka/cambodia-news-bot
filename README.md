# Новостной бот @CambodlaNews

Бот 3 раза в день (8:00, 14:00, 20:00 по Пномпеню) собирает свежие новости Камбоджи за вчера и сегодня,
выбирает самые интересные, включая криминал, скам-центры и ДТП, а не только официальные новости. Пишет посты на русском с
цепляющим заголовком, эмодзи и фото, а если в новости есть видео — добавляет ссылку на него. Публикует в
**@CambodlaNews**, а лучшую новость пересылает в чат **@Cambodia_Russ** и закрепляет. При следующем выпуске
закреп заменяется на свежий.

Бот работает **бесплатно в облаке GitHub** (GitHub Actions), поэтому MacBook может спать, быть закрыт или выключен.

| Что | Чем | Цена |
|---|---|---|
| Сервер и расписание | GitHub Actions (публичный репозиторий) | бесплатно, без лимита минут |
| Отбор и перевод новостей | Google Gemini API, бесплатный уровень | бесплатно, ~6 запросов в день |
| Запасной ИИ, если Gemini упрётся в лимит | GitHub Models (встроен в GitHub, ключ не нужен) | бесплатно, ~150 запросов в день |
| Последний запасной вариант, если ИИ недоступен | отбор по ключевым словам + Google Translate | бесплатно |

Источники: Telegram-каналы @khmertimesbreakingnews и @thephnompenhpost (через их публичную веб-версию, без
аккаунта), RSS Khmer Times и CamboJA News. Список правится в `bot.py` → `SOURCES`.

## Настройка (один раз, ~20 минут)

### 1. Бот в Telegram
1. Откройте **@BotFather** → `/newbot` (или используйте вашего прежнего бота) → скопируйте **токен**.
2. Канал **@CambodlaNews** → Администраторы → Добавить → ваш бот. Права: **Публикация сообщений**,
   **Изменение профиля канала** (нужно только для записи описания).
3. Чат **@Cambodia_Russ** → Администраторы → Добавить → ваш бот. Права: **Закрепление сообщений**,
   **Удаление сообщений**.
4. В настройках канала **не включайте** «Запретить копирование»: иначе бот не сможет переслать новость в чат
   с подписью «Переслано из…» и отправит её копией.

### 2. Бесплатный ключ Gemini
Откройте https://aistudio.google.com → **Get API key** → **Create API key** → скопируйте ключ (`AIza…`).
Карта не нужна.

### 3. Репозиторий на GitHub (в Терминале на Mac)
```bash
# если ещё нет Homebrew: https://brew.sh
brew install gh
gh auth login                      # GitHub.com → HTTPS → Login with a web browser

cd ~/Downloads/cambodia-news-bot   # папка, куда распаковали архив
chmod +x run_now.sh
git init -b main && git add . && git commit -m "news bot"
gh repo create cambodia-news-bot --public --source=. --remote=origin --push

gh secret set BOT_TOKEN            # вставьте токен бота и нажмите Enter
gh secret set GEMINI_API_KEY       # вставьте ключ Gemini и нажмите Enter
```
Почему **публичный** репозиторий: в нём минуты GitHub Actions не ограничены. Токены в Secrets **никто не видит**,
даже в публичном репозитории. В приватном репозитории 2000 бесплатных минут в месяц, а бот тратит ~1500–2000 (из-за
ожидания точного времени), поэтому там может не хватить.

Всё: расписание включено. Проверить запуски можно на GitHub → вкладка **Actions**.

### 4. Проверка и первый запуск
Для проверки с Mac создайте `.env` (ключи хранятся только у вас на ноутбуке):
```bash
cp .env.example .env
open -e .env                       # вставьте BOT_TOKEN и GEMINI_API_KEY, сохраните

./run_now.sh check                 # источники, Gemini и права бота — везде должно быть ✅
./run_now.sh preview               # покажет посты в терминале, ничего не отправит
./run_now.sh description           # запишет описание канала
./run_now.sh                       # опубликовать прямо сейчас
```

## Ручной запуск с MacBook (пункт 14)
```bash
cd ~/Downloads/cambodia-news-bot
./run_now.sh             # опубликовать сейчас: 3 новости + обновить закреп (запуск в облаке GitHub)
./run_now.sh 2           # опубликовать 2 новости
./run_now.sh nopin       # опубликовать без обновления закрепа в чате
./run_now.sh preview     # только посмотреть, что бот опубликует
./run_now.sh local       # опубликовать прямо с Mac, без GitHub
```
Можно и без Терминала: GitHub → Actions → **Cambodia News** → **Run workflow**.

## Как это работает
- **Время.** GitHub запускает бота в 7:45, 13:45 и 19:45. Бот собирает новости, пишет посты и ждёт ровно 8:00, 14:00 и 20:00.
  GitHub иногда запускает задачу с опозданием. Если опоздание больше 15 минут, бот публикует сразу, как запустится.
- **Свежесть.** Бот берёт только новости, опубликованные со вчерашних 00:00 по Пномпеню.
- **Без повторов.** Опубликованное записывается в `state.json` (бот сам сохраняет его в репозиторий).
  Одинаковые новости из разных источников склеиваются, а похожие на уже опубликованные пропускаются.
- **Фото.** Фото берётся из поста-источника или из статьи (og:image). Если фото нет, пост уходит текстом с превью ссылки.
- **Видео.** Если в источнике есть видео (в Telegram-посте или YouTube в статье), в пост добавляется «🎥 Смотреть видео».
- **Закреп.** Бот пересылает лучшую новость в чат без звука, закрепляет её, а прошлую новость бота открепляет и удаляет.
  Ваш собственный закреп («Решаем вопросы в Phnom Penh…») остаётся закреплённым. В Telegram в группе может быть
  несколько закрепов, и сверху показывается самый новый.

## Настройки (необязательно)
GitHub → Settings → Secrets and variables → Actions → **Variables**:
- `NEWS_PER_RUN` — сколько новостей за выпуск (по умолчанию 3);
- `CHANNEL`, `CHAT` — если поменяете юзернеймы.

Для локального запуска эти же параметры задаются в `.env`. Там же есть `PIN_ENABLED=0` (выключить закреп) и
`PIN_DELETE_OLD=0` (не удалять прошлую новость, только откреплять).
Время выпусков меняется в `.github/workflows/news.yml` (cron в UTC, Пномпень = UTC+7) и в переменной `SLOTS`.

## Если что-то не так
- **В Actions красный крестик.** GitHub пришлёт письмо. Откройте запуск и посмотрите лог: строки с ❌ и ⚠️ покажут причину.
- **«Gemini недоступен».** Бот всё равно опубликует новости в запасном режиме, но заголовки будут проще.
  Проверьте ключ (`./run_now.sh check`). Если Google переименовал модели, укажите новую в переменной `GEMINI_MODELS`.
- **Источник ❌ в `check`.** Бот его пропускает, остальные работают. Можно удалить его из `SOURCES` или заменить адрес.
- **Сообщение «бот закрепил сообщение» в чате.** Это служебная плашка Telegram. Её можно отключить только вручную.
